## Чтения

- 汚す（よごす）— пачкать, загрязнять: существующая заметка сохранена.
- 汚す（けがす）— осквернять, пятнать честь: новая заметка.
- 汚れる（よごれる）— пачкаться: существующая заметка сохранена.
- 汚れる（けがれる）— оскверняться, утрачивать духовную чистоту: новая заметка.

汚る — литературная форма; для современного языка используются 汚す и 汚れる. Различие значений проверено по [大辞泉 / 日本国語大辞典: 汚す](https://kotobank.jp/word/汚す-489607) и [汚れる](https://kotobank.jp/word/汚れる-489621). Области употребления пересекаются: разделение на физическую и духовную грязь — типичная тенденция, не абсолютное правило.

Новые чтения не помечены уроками Minna: это расширенная лексика. В поле «Слово» сохраняется обычная запись кандзи; имена дополнительных JSON и медиа содержат чтение в скобках. Синхронизация теперь выбирает заметку по паре «Слово»/«Чтение» и пропускает неоднозначные совпадения.
