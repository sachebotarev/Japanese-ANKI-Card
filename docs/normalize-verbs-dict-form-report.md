# Нормализация глаголов в словарную форму

Дата: 2026-05-28. Скрипт: `scripts/normalize_verb_dictionary_form.py`.

## Итог

- JSON в `Карточки/Глаголы/`: **352 → 333** (−19 дубликатов/форм)
- Все поля «Слово» — словарная форма (исключение: **覚ます** — это уже 辞書形)
- Исправлены поля «Чтение» с ます-чтением при словарном «Слово» (52 карточки)
- Anki: удалено **20** устаревших заметок, обновлено **332**, создана **1** (`演奏する`)

## Примечания

- Устойчивые фразы в других темах (`失礼します`, `お邪魔します` и т.п.) **не** затронуты — это не глаголы в `Карточки/Глаголы/`.
- Примеры в предложениях могут оставаться в ます/た/て формах; словарная форма обязательна в полях «Слово» и «Чтение».
