# Связь таксономии с папками репозитория

Таксономия из [theme-taxonomy.md](theme-taxonomy.md) шире, чем текущий набор каталогов в `Карточки/`. При добавлении слова сначала выбирают **пункт таксономии**, затем — **существующую папку** из второго столбца (или создают новую папку с именем из таксономии, если накопилась группа и это оправдано).

Актуальные имена папок после выравнивания (май 2026): **Образование**, **Торговля**, **Еда**, **Жилище**, **Одежда**, **Право**, **Туризм**, **Дружба**, **Кинематограф**, **Телевидение**, **Фотография**, **Электроника**, **Медицина**, **Эмоции** (вместо прежних Учёба, Покупки, Продукты, Жильё, Гардероб, Правопорядок, Достопримечательности, части Общение/Медиа/Здоровье).
