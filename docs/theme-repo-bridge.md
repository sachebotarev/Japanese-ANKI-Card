# Связь таксономии с папками репозитория

Таксономия из [theme-taxonomy.md](theme-taxonomy.md) шире, чем текущий набор каталогов в `Карточки/`. При добавлении слова сначала выбирают **пункт таксономии**, затем — **существующую папку** из второго столбца (или создают новую папку с именем из таксономии, если накопилась группа и это оправдано).

Папки **Канцелярия**, **Почта**, **Счётные суффиксы**, **Вопросительные слова** не дублируют номера таксономии дословно: их оставляют как учебные/служебные темы; новые слова из зоны «74 Числа» по возможности ведут в **Счётные суффиксы**, канцтовары — в **Канцелярия**.

**Глаголы**, **Наречия**, **Прилагательные_い**, **Прилагательные_на** в эту таблицу не входят — для них действуют только свои каталоги.
