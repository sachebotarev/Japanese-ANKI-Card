# Таксономия тем для классификации лексики

Список ниже — **ориентир для выбора смысловой темы** при добавлении и разборе карточек (существительные, устойчивые словосочетания, тематическая лексика и т.д.).

**Не относится к этой таксономии как к «ящику для переноса»:** каталоги **Глаголы**, **Наречия**, **Прилагательные_い**, **Прилагательные_на** — их не переклассифицируют по этому списку; глаголы и наречия остаются в своих грамматических темах, прилагательные — в своих.

Имя папки в `Карточки/<тема>/` по-прежнему должно совпадать с файлом в `Слова/<тема>` (см. [word-lists.md](word-lists.md)). Пока в репозитории **прагматический набор папок** — не все 100 пунктов имеют отдельную папку. Выбор: либо ближайшая существующая папка (см. [theme-repo-bridge.md](theme-repo-bridge.md)), либо новая папка по правилам из `word-lists.md`, **название новой папки по возможности совпадает с пунктом таксономии** (одно слово, без «и»), если это не ломает уже принятую структуру.
