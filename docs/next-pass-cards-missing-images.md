# Карточки без локальной картинки

Осталось без картинки: **0**.

На 2026-07-17 у всех JSON в `Карточки/` есть локальный файл в `Картинки/<тема>/<Слово>.png` (или иной допустимый растровый формат), а поле `Картинка` в JSON приведено к HTML `<img src="japanese_words_….png">` после импорта через `scripts/import_card_image.py`.

Этот файл — рабочий чеклист на будущие проходы: если появятся новые карточки без иллюстрации, сюда можно снова выгрузить список. Ожидаемый файл: `Картинки/<тема>/<Слово>.(png|jpg|jpeg|webp)`.

Правила генерации и импорта: [cards-spec.md](cards-spec.md) (раздел «Правила для картинки»), промпты для anime-сцен — [prompt-generation-rule.md](prompt-generation-rule.md).
