# Карточки без локальной картинки

Осталось без картинки: **422** (после партии 09 от 2026-09-24).

На 2026-07-17 у всех тогдашних JSON в `Карточки/` был локальный файл в `Картинки/<тема>/<Слово>.png` (или иной допустимый растровый формат). После импорта Minna no Nihongo 2026-09-16 появились новые карточки без иллюстраций. Первые 180 картинок добавлены партиями по 20; обработанные карточки перечислены в `minna-import-2026-09-16/images-batch-01.json` … `images-batch-09.json`.

Этот файл — рабочий чеклист на будущие проходы: если появятся новые карточки без иллюстрации, сюда можно снова выгрузить список. Ожидаемый файл: `Картинки/<тема>/<Слово>.(png|jpg|jpeg|webp)`.

Правила генерации и импорта: [cards-spec.md](cards-spec.md) (раздел «Правила для картинки»), промпты для anime-сцен — [prompt-generation-rule.md](prompt-generation-rule.md).
