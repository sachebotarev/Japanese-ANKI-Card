# Импорт лексики Minna no Nihongo, 16 сентября 2026

Источник: `Japanese::Minna no Nihongo 1 & 2 (Chapters 1-50)`, 2109 заметок.
Назначение: `Японские слова`, до импорта 1999 заметок.

Подготовлено 606 новых слов и устойчивых выражений. Имена собственные и грамматические шаблоны исключены. Сопоставление учитывает кану/кандзи, словарные и ます-формы, основы な-прилагательных, существительные и уже имеющиеся сочетания с する. Совпадения чтения проверены по значению: 機会/機械, 橋/はし, 易しい/優しい и другие омонимы не объединены. Устаревшие промежуточные решения в `minna_decisions.json` и `minna_refined.json` переопределяются `manual-exclusions.json`; окончательный состав — только `created.json`.

Для каждой карточки подготовлены русские перевод, подсказка и пояснения, чтение, разбор кандзи, три японских примера с переводами и пропусками, теги темы и урока. Изображения отложены по прямому указанию пользователя. В JSON оставлены исходные промпты для отдельного этапа иллюстраций; в Anki поле картинки пустое. `Записи/` пропущены, поскольку обязательных изображений ещё нет; пустые заметки не создавались.

Озвучка: AivisSpeech, скорость 90%, отдельный случайный выбор разрешённого голоса для каждой фразы. На карточку — слово и три примера, всего 2424 MP3. Для отдельных слов используется поле чтения, чтобы избежать неоднозначного чтения кандзи. Журнал `audio-log.jsonl` хранит фактический текст синтеза, голос и SHA256; прежние версии записей сохранены, актуальная запись для файла — последняя.

## Воспроизведение и контроль

Сборщики `scripts/build_minna_import_2026_09.py` и `scripts/minna_import_{groups,verbs,custom,more_groups}_2026_09.py` используют зафиксированные входные данные этой папки. По умолчанию существующие карточки пропускаются; `MINNA_REFRESH=1` обновляет только принадлежащие этому импорту карточки, сохраняя ссылки на аудио. После сборщиков выполняется `scripts/minna_import_finalize_2026_09.py`, затем `scripts/minna_import_audio_2026_09.py`.

`scripts/minna_import_validate_2026_09.py` проверяет структуру, согласованность примеров и пропусков, списки слов, контрольные суммы и полный декод MP3. Опция `--upload-media` загружает только аудио активного манифеста через локальный AnkiConnect. Имена медиа, нормализованные Anki, фиксируются в `media-names.json`; ссылки в JSON используют фактические имена Anki, локальные MP3 сохраняют имя слова. Заметки создаются пакетами через MCP Anki; результаты сохраняются в `anki-results.json`.

## Справочные данные

- Фуригана: [список Basic Kanji Book Vol. 1 в KanjiBox](https://kanjibox.net/kb/set/2708/name/basic_kanji_book_vol_1), 251 кандзи, локальная копия `basic-kanji-book-1.txt`.
- Уровни JLPT: [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks), лицензия MIT приложена. Это справочные, а не официальные уровни. Для точных совпадений использован словарь; для остальных сохранена предварительная оценка N5/N4 по тому учебника. Исходные переводы и примеры этого словаря не копировались.
- Теги уроков взяты из исходной колоды; для 初級 II номера 26–50 преобразованы в 01–25. Для глагола いただく указан урок 41 (II-16), а не урок с репликой いただきます.

## Загрузка в Anki

Перед записью повторно проверены 12 полей типа заметки и отсутствие точных совпадений всех 606 слов в целевой колоде. Первые 9 слов Anki отклонил своей проверкой дубликатов вне целевой колоды; после проверки отсутствия этих слов в «Японские слова» они добавлены с разрешением межколодного совпадения. Следующие пакеты используют ту же настройку. Повторять загрузку без проверки целевой колоды нельзя.

Добавлен общий тег `Импорт::Minna_2026_09_16`. Тип заметки создаёт четыре учебные карточки на слово.

Anki канонизирует регистр уже существующих тегов (`Календарь` → `календарь`) и разделяет теги с пробелами (`Счётные суффиксы`, `Вопросительные слова`). В JSON сохранены названия тем по правилам репозитория; проверка тегов учитывает эту штатную нормализацию Anki.
