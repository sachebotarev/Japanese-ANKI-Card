# Проверка 70 пар переходных и непереходных глаголов

Источник: Meguro Language Center, «自動詞と他動詞 — 70 pairs», страницы 2–8 предоставленного пособия.

Итог первого прохода: 70 полных пар, 140 самостоятельных заметок с тегом `pair` в колоде «Японские слова»; затем набор расширен по списку из 100 пар, см. [pair-100-audit.md](pair-100-audit.md). Создано 27 новых заметок, 27 иллюстраций встроенным image_gen и 108 MP3 через AivisSpeech (90%, случайный разрешённый голос для каждой фразы).

Первоначальные 121 совпадение включали шесть словосочетаний, дублирующее написание 付ける и 付く в значении «прикрепляться». С этих восьми заметок снят `pair`; самостоятельные карточки и остальные теги сохранены. Для значения «свет загорается» добавлено 点く（つく）, а для «открываться» — 開く（あく）, отдельно от 開く（ひらく）.

## Файлы и проверка

- JSON, картинки, аудио и Markdown находятся в соответствующих каталогах темы `Глаголы`.
- Для каждой новой карточки проверены три согласованных примера, изображение и четыре MP3.
- После загрузки проверено наличие `pair`, совпадение полей с JSON и содержимое медиа Anki.
- Промпты иллюстраций сохранены в `docs/pair-70-manifest.json`; все сцены опираются на третий пример.
- Учебные теги уроков сохранены в принятой в репозитории нумерации внутри тома: 開く и 点く — 初級II-第04課 (общий урок 29), 外す — 初級II-第08課 (общий урок 33).
