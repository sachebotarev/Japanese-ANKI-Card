# 歯

は

зуб; зубы

![[Произношение/Анатомия/歯_слово.mp3]]

![[Картинки/Анатомия/歯.png]]

## Примеры

### Пример 1

![[Произношение/Анатомия/歯_пример_1.mp3]]

毎晩**歯**を磨きます。

Я чищу зубы каждый вечер.

### Пример 2

![[Произношение/Анатомия/歯_пример_2.mp3]]

甘いものを食べすぎると**歯**が悪くなります。

Если есть слишком много сладкого, зубы портятся.

### Пример 3

![[Произношение/Анатомия/歯_пример_3.mp3]]

定期的に歯医者に行って**歯**の検査をしてもらうと、虫歯を早めに見つけることができます。

Регулярно посещая стоматолога для осмотра зубов, можно обнаружить кариес на ранней стадии.

## Заметки

Используется в единственном числе для общего понятия «зубы». 歯医者（はいしゃ）— зубной врач.

## Кандзи-разбор

歯 (シ, は) — «зуб».
