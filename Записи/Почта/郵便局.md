# 郵便局

ゆうびんきょく

почта; почтовое отделение

## Примеры

### Пример 1

![[Произношение/Почта/郵便局_пример_1.mp3]]

**郵便局**で荷物を出します。

На почте отправлю посылку.

### Пример 2

![[Произношение/Почта/郵便局_пример_2.mp3]]

**郵便局**は土曜も午前だけ開いています。

По субботам открыто только утром — запоминаю режим работы.

### Пример 3

![[Произношение/Почта/郵便局_пример_3.mp3]]

**郵便局**の前に映画チラシが貼ってあったので試験資料を出したあと上映時間を読みました。

У входа висел постер фильма и после отправки бумаг к экзамену успел записать сеансы с афиши.

## Заметки

Смежные слова 郵便ポスト, 郵便番号.

## Кандзи-разбор

郵 доставка сообщений; 便 регулярный ход; 局 учреждение.
