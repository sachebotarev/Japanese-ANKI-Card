# 入力する

にゅうりょくする

вводить данные

![[Произношение/Глаголы/入力する_слово.mp3]]

![[Картинки/Глаголы/入力する.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/入力する_пример_1.mp3]]

名前を**入力します**。

Я ввожу имя.

### Пример 2

![[Произношение/Глаголы/入力する_пример_2.mp3]]

ここに住所を**入力してください**。

Введите здесь адрес.

### Пример 3

![[Произношение/Глаголы/入力する_пример_3.mp3]]

間違えないように、番号をゆっくり**入力して**、もう一度確かめました。

Чтобы не ошибиться, я медленно ввёл номер и ещё раз проверил его.

## Заметки



**Спряжение:** III группа（サ変）: 入力します・入力しない・入力して

**Переходность:** Переходный（他動詞）.

**Частицы:** 名前／番号をフォームに入力する — ввести имя／номер в форму: данные с を, место ввода с に. キーボードで — клавиатурой.

**Особенности:** Подразумевает внесение данных в систему. для простой записи на бумаге обычно 書く／記入する.

## Кандзи-разбор

入 — входить; 力 — сила
