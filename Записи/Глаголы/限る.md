# 限る

かぎる

ограничивать; ограничиваться

![[Произношение/Глаголы/限る_слово.mp3]]

![[Картинки/Глаголы/限る.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/限る_пример_1.mp3]]

予算を三万円に**限ります**。

Ограничиваю бюджет тремядцатью тысячами иен.

### Пример 2

![[Произношение/Глаголы/限る_пример_2.mp3]]

出入りは関係者に**限ります**。

Вход только для сотрудников.

### Пример 3

![[Произношение/Глаголы/限る_пример_3.mp3]]

安全のため、立ち入りは許可された者に**限る**ことになり、違反した場合は退場となります。

Из соображений безопасности доступ ограничен разрешёнными лицами; при нарушении — удаление.

## Заметки


五段: 限る→限ります. Управление: を/に — 予算を三万円に限る. Отдельное значение «только» — 〜に限る.

Переходность: Глагол с переходным и непереходным употреблением (自他動詞; лабильный в широком учебном смысле). 人数を限る — ограничивать число людей; 今日に限る — ограничиваться сегодняшним днём. Отдельная форма для смены переходности не обязательна.

## Кандзи-разбор

限(かぎ)=предел → 限る=ограничивать.
