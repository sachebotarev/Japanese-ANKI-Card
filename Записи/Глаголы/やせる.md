# やせる

やせる

худеть; становиться тоще

![[Произношение/Глаголы/やせる_слово.mp3]]

![[Картинки/Глаголы/やせる.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/やせる_пример_1.mp3]]

最近、**やせました**。

В последнее время похудел.

### Пример 2

![[Произношение/Глаголы/やせる_пример_2.mp3]]

運動して**やせたい**です。

Хочу похудеть с помощью спорта.

### Пример 3

![[Произношение/Глаголы/やせる_пример_3.mp3]]

病気のあと少し**やせて**しまったので、栄養のある食事を心がけています。

После болезни немного похудел, поэтому стараюсь есть полезную пищу.

## Заметки


**Спряжение:** II группа（一段）: やせます・やせない・やせて

**Переходность:** Непереходный（自動詞）.

**Частицы:** 人がやせる — человек худеет, субъект с が. величина изменения без частицы: 三キロやせる.

**Особенности:** やせている — быть худым, состояние результата. 太る — толстеть, смысловая противоположность, а не переходная пара. Не означает само по себе намеренно соблюдать диету.
