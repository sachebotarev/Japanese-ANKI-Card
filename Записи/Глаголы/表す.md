# 表す

あらわす

выражать; показывать

![[Произношение/Глаголы/表す_слово.mp3]]

![[Картинки/Глаголы/表す.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/表す_пример_1.mp3]]

感謝を言葉で**表します**。

Выражаю благодарность словами.

### Пример 2

![[Произношение/Глаголы/表す_пример_2.mp3]]

絵で気持ちを**表しました**。

Я выразил свои чувства рисунком.

### Пример 3

![[Произношение/Глаголы/表す_пример_3.mp3]]

日本語では、尊敬の気持ちを敬語を使って**表す**ことができます。

В японском языке уважение можно выразить с помощью вежливой речи.

## Заметки

表す — переходный глагол: то, что выражают или показывают, обычно идет с を: 気持ちを表す. Пара по смыслу — 表れる; если признак проявился сам, естественнее непереходный вариант.

Переходность: Переходный глагол (他動詞). Пара: 表れる（あらわれる）— непереходный.

## Кандзи-разбор

表す — разбор по значению слова: «выражать; показывать»; чтение: あらわす.
