# 進める

すすめる

продвигать; продвигаться; ускорять; рекомендовать

![[Произношение/Глаголы/進める_слово.mp3]]

![[Картинки/Глаголы/進める.jpg]]

## Примеры

### Пример 1

![[Произношение/Глаголы/進める_пример_1.mp3]]

仕事を**進めます**。

Продвигаю работу вперёд.

### Пример 2

![[Произношение/Глаголы/進める_пример_2.mp3]]

プロジェクトを少しずつ**進めて**います。

Постепенно продвигаю проект.

### Пример 3

![[Произношение/Глаголы/進める_пример_3.mp3]]

計画を予定通りに**進める**ために、毎日チームで話し合いをしています。

Чтобы продвигать план по расписанию, команда проводит встречи каждый день.

## Заметки



**Спряжение:** II группа（一段）: 進めます・進めない・進めて

**Переходность:** Переходный（他動詞）.

**Пара:** 進む（すすむ）— непереходный

**Частицы:** 仕事／計画を進める — продвигать работу／план: продвигаемое с を. 話を次の段階に進める — перевести обсуждение к следующему этапу, итоговый этап с に. Пара 進む: 仕事が進む — работа продвигается.

**Особенности:** Для «рекомендовать／советовать» обычно пишут 勧める／薦める. не смешивать это с основным значением 進める.

## Кандзи-разбор

進(すす)める=продвигать → 進める=продвигать, рекомендовать
