# 送れる

おくれる

уметь отправить; быть отправляемым

![[Произношение/Глаголы/送れる_слово.mp3]]

![[Картинки/Глаголы/送れる.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/送れる_пример_1.mp3]]

このアプリでメールが**送れます**。

С помощью этого приложения можно отправлять письма.

### Пример 2

![[Произношение/Глаголы/送れる_пример_2.mp3]]

スマホで写真が**送れます**。

Со смартфона можно отправлять фотографии.

### Пример 3

![[Произношение/Глаголы/送れる_пример_3.mp3]]

インターネットがあれば、どこからでもファイルが**送れる**ので、とても便利です。

Если есть интернет, файлы можно отправлять откуда угодно — это очень удобно.

## Заметки


**Спряжение:** II группа（一段）: 送れます・送れない・送れて

**Переходность:** Потенциальная форма переходного 送る; не самостоятельная непереходная пара.

**Частицы:** адресат с に／へ.

**Особенности:** Потенциальная форма 送る: メールが送れる／メールを送れる — можно отправить письмо, возможны が и を. Не страдательная форма: «быть отправленным» — 送られる. Омоним 遅れる（おくれる） означает опаздывать и не является парой по переходности. Потенциальная форма переходного 送る（おくる）— отправлять. не путать с непереходным 遅れる（おくれる）— опаздывать, это не его пара.

## Кандзи-разбор

送れる — разбор по значению слова: «уметь отправить; быть отправляемым»; чтение: おくれる.
