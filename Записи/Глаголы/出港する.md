# 出港する

しゅっこうする

выходить из порта; отправляться из гавани

![[Произношение/Глаголы/出港する_слово.mp3]]

![[Картинки/Глаголы/出港する.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/出港する_пример_1.mp3]]

船は朝**出港しました**。

Судно вышло из порта утром.

### Пример 2

![[Произношение/Глаголы/出港する_пример_2.mp3]]

フェリーは九時に港を**出港します**。

Паром выходит из порта в девять часов.

### Пример 3

![[Произношение/Глаголы/出港する_пример_3.mp3]]

風が強かったので、船長は天気を確認してから、船を**出港させました**。

Так как ветер был сильным, капитан проверил погоду, а затем вывел судно из порта.

## Заметки

出港する — する-глагол, для места отправления обычно используется を: 港を出港する. Если подчёркивается судно как субъект, говорят 船が出港する.

## Кандзи-разбор

出 — приходи/выходи; 港 — порт, гавань
