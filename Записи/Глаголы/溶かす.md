# 溶かす

とかしする

растворять; топить; распускать (волосы, клубок)

![[Произношение/Глаголы/溶かす_слово.mp3]]

![[Картинки/Глаголы/溶かす.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/溶かす_пример_1.mp3]]

チョコレートを**溶かす**。

Растопить шоколад.

### Пример 2

![[Произношение/Глаголы/溶かす_пример_2.mp3]]

氷を溶かします。

Растопить лёд.

### Пример 3

![[Произношение/Глаголы/溶かす_пример_3.mp3]]

髪を**溶かす**。

Расчесать волосы.

## Заметки

глагол 五段; часто используется с を для объекта действия
