# 閉会する

へいかいする

закрывать собрание; завершать мероприятие

![[Произношение/Глаголы/閉会する_слово.mp3]]

![[Картинки/Глаголы/閉会する.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/閉会する_пример_1.mp3]]

会議を**閉会します**。

Закрываю собрание.

### Пример 2

![[Произношение/Глаголы/閉会する_пример_2.mp3]]

大会を**閉会する**式があります。

Есть церемония закрытия соревнований.

### Пример 3

![[Произношение/Глаголы/閉会する_пример_3.mp3]]

長い会議の最後に、司会者が挨拶をして「これにて**閉会します**」と宣言しました。

В конце долгого собрания ведущий выступил с заключительным словом и объявил: «На этом собрание закрыто».

## Заметки

動詞（サ変）; формальный термин для завершения официальных мероприятий или собраний; противоположность — 開会する（かいかいする）

Переходность: Глагол с переходным и непереходным употреблением (自他動詞; лабильный в широком учебном смысле). 会議を閉会する — закрыть заседание; 会議が閉会する — заседание закрывается. Отдельная форма для смены переходности не обязательна.

## Кандзи-разбор

閉(へい)=закрывать; 会(かい)=собрание → 閉会する=закрывать собрание, завершать мероприятие
