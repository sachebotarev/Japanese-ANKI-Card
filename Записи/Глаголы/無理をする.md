# 無理をする

むりをする

перенапрягаться; делать через силу

![[Произношение/Глаголы/無理をする_слово.mp3]]

![[Картинки/Глаголы/無理をする.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/無理をする_пример_1.mp3]]

**無理をしないで**ください。

Пожалуйста, не перенапрягайтесь.

### Пример 2

![[Произношение/Глаголы/無理をする_пример_2.mp3]]

体調が悪いのに**無理をしました**。

Несмотря на плохое самочувствие, перетрудился.

### Пример 3

![[Произношение/Глаголы/無理をする_пример_3.mp3]]

風邪のとき**無理をして**出かけたので、かえって治りが遅くなりました。

При простуде вышел через силу — из-за этого болезнь прошла медленнее.

## Заметки

する表現; 無理をする/しない.

## Кандзи-разбор

無理(むり)+する
