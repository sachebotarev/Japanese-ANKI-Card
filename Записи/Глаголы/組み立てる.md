# 組み立てる

くみたてる

собирать из деталей

![[Произношение/Глаголы/組み立てる_слово.mp3]]

![[Картинки/Глаголы/組み立てる.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/組み立てる_пример_1.mp3]]

机を**組み立てます**。

Я собираю стол.

### Пример 2

![[Произношение/Глаголы/組み立てる_пример_2.mp3]]

父と椅子を**組み立てました**。

Мы с отцом собрали стул.

### Пример 3

![[Произношение/Глаголы/組み立てる_пример_3.mp3]]

説明書を読みながら、本棚を**組み立てて**みましたが、思ったより時間がかかりました。

Я попробовал собрать книжный шкаф по инструкции, но это заняло больше времени, чем я думал.

## Заметки



**Спряжение:** II группа（一段）: 組み立てます・組み立てない・組み立てて

**Переходность:** Переходный（他動詞）.

**Частицы:** 家具／機械を部品から組み立てる — собрать мебель／механизм из деталей: готовый предмет с を, исходные детали с から.

**Особенности:** 組み立ててある — уже собрано для использования. 積む — сложить стопкой, а 組み立てる требует соединить части в конструкцию.

## Кандзи-разбор

組 — собирать; 立 — ставить
