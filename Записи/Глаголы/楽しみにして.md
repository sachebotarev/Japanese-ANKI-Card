# 楽しみにして

たのしみにして

с нетерпением ждать; предвкушать (форма ～て)

![[Произношение/Глаголы/楽しみにして_слово.mp3]]

![[Картинки/Глаголы/楽しみにして.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/楽しみにして_пример_1.mp3]]

旅行を**楽しみにして**います。

С нетерпением жду поездку.

### Пример 2

![[Произношение/Глаголы/楽しみにして_пример_2.mp3]]

明日の試合を**楽しみにして**。

Жду с нетерпением завтрашний матч.

### Пример 3

![[Произношение/Глаголы/楽しみにして_пример_3.mp3]]

友だちの結婚式を**楽しみにして**チケットを予約し、服も新しく買いました。

С нетерпением ждал свадьбу друга — забронировал билет и купил новую одежду.
