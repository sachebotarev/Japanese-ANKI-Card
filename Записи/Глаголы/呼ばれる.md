# 呼ばれる

よばれる

быть названным; быть званым; быть вызванным

![[Произношение/Глаголы/呼ばれる_слово.mp3]]

![[Картинки/Глаголы/呼ばれる.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/呼ばれる_пример_1.mp3]]

彼は田中と呼ばれています。

Его называют Танака.

### Пример 2

![[Произношение/Глаголы/呼ばれる_пример_2.mp3]]

名前を呼ばれて返事をしました。

Меня позвали по имени, и я ответил.

### Пример 3

![[Произношение/Глаголы/呼ばれる_пример_3.mp3]]

パーティーに呼ばれました。

Меня пригласили на вечеринку.

## Заметки



**Спряжение:** II группа（一段）: 呼ばれます・呼ばれない・呼ばれて

**Переходность:** Страдательная／спонтанная производная форма; не самостоятельная непереходная пара.

**Пара:** 呼ぶ→呼ばれる — образование страдательного залога, не отдельная лексическая пара.

**Частицы:** 先生に名前を呼ばれる — учитель вызывает по имени: に — тот, кто зовёт, が／は — вызываемый; 名前を сохраняет を.

**Особенности:** Страдательная форма 呼ぶ. В 名を呼ばれる вызывают по имени; AはBと呼ばれる — A называют B, と — название.

## Кандзи-разбор

呼(よ)ぶ=звать → 呼ばれる=быть званным, быть вызванным
