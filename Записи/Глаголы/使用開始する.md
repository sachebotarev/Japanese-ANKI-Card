# 使用開始する

しようかいしする

начинать использовать; запускать использование

![[Произношение/Глаголы/使用開始する_слово.mp3]]

![[Картинки/Глаголы/使用開始する.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/使用開始する_пример_1.mp3]]

この機械を**使用開始します**。

Начинаю использовать эту машину.

### Пример 2

![[Произношение/Глаголы/使用開始する_пример_2.mp3]]

**使用開始**は明日です。

Начало использования завтра.

### Пример 3

![[Произношение/Глаголы/使用開始する_пример_3.mp3]]

仕事で必要な新しいソフトを昨日の朝に**使用開始した**ばかりなので、まだ使い方に慣れていません。

Я только вчера утром начал пользоваться новой рабочей программой, поэтому ещё не привык к ней.

## Заметки


**Спряжение:** III группа（サ変）: 使用開始します・使用開始しない・使用開始して

**Переходность:** Переходный（他動詞）.

**Частицы:** Более прозрачная полная модель — 機械の使用を開始する／機械を使い始める: 使用 с を, устройство с の или を при 使う. 使用開始は明日です — именная конструкция «начало использования завтра», а не спряжение глагола.

**Особенности:** Официальное составное обозначение начала использования. изменяется する.

## Кандзи-разбор

使用(しよう)=использование; 開始(かいし)=начало
