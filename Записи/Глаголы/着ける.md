# 着ける

つける

надевать (аксессуары), прикреплять на тело

![[Произношение/Глаголы/着ける_слово.mp3]]

![[Картинки/Глаголы/着ける.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/着ける_пример_1.mp3]]

指輪を**着ける**。

Надеть кольцо.

### Пример 2

![[Произношение/Глаголы/着ける_пример_2.mp3]]

イヤリングを**着ける**。

Надеть серьги.

### Пример 3

![[Произношение/Глаголы/着ける_пример_3.mp3]]

ネクタイを**着ける**。

Надеть галстук.

## Заметки

動詞・一段; используется для аксессуаров: 指輪・ネクタイ・イヤリング など

## Кандзи-разбор

着(つ)=надевать, прикладывать
