## Заметки



**Спряжение:** II группа（一段）: 宿題が出ます・宿題が出ない・宿題が出て

**Переходность:** Непереходный（自動詞）.

**Пара:** 宿題を出す — переходное выражение: учитель задаёт домашнее задание.

**Частицы:** 先生から宿題が出る — преподаватель задаёт домашнее задание: 宿題 с が, источник с から. 先生が宿題を出す — учитель задаёт задание, переходная пара с を. для этого 宿題をする.

**Особенности:** Выражение не означает выполнить домашнюю работу.
