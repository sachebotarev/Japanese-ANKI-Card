# 取り出す

とりだす

вынимать; доставать

![[Произношение/Глаголы/取り出す_слово.mp3]]

![[Картинки/Глаголы/取り出す.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/取り出す_пример_1.mp3]]

かばんから本を**取り出します**。

Я достаю книгу из сумки.

### Пример 2

![[Произношение/Глаголы/取り出す_пример_2.mp3]]

財布からカードを**取り出しました**。

Я достал карточку из кошелька.

### Пример 3

![[Произношение/Глаголы/取り出す_пример_3.mp3]]

市役所で必要な書類を出すために、かばんから封筒を**取り出しました**。

Чтобы подать нужные документы в мэрии, я достал из сумки конверт.

## Заметки

動詞・五段。他動詞: обычно `ものを場所から取り出す`.

## Кандзи-разбор

取(と)=брать + 出(だ)=вынимать, выводить.
