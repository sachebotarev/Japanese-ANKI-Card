# 帰す

かえしする

отпускать домой; отправлять обратно

![[Произношение/Глаголы/帰す_слово.mp3]]

![[Картинки/Глаголы/帰す.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/帰す_пример_1.mp3]]

子供を家に帰します。

Отправляю ребенка домой.

### Пример 2

![[Произношение/Глаголы/帰す_пример_2.mp3]]

社員を早く帰しました。

Отправил сотрудников домой пораньше.

### Пример 3

![[Произношение/Глаголы/帰す_пример_3.mp3]]

友達を駅まで帰します。

Отправляю друга до станции.

## Заметки

う動詞; ます-форма — かえします; используется для действия по возвращению кого-либо

## Кандзи-разбор

帰(かえ)=возвращать, возвращаться; す=суффикс глагола
