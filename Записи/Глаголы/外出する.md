# 外出する

がいしゅつする

выходить из дома; уходить наружу

![[Произношение/Глаголы/外出する_слово.mp3]]

![[Картинки/Глаголы/外出する.png]]

## Примеры

### Пример 1

![[Произношение/Глаголы/外出する_пример_1.mp3]]

午後に**外出します**。

После полудня выйду из дома.

### Пример 2

![[Произношение/Глаголы/外出する_пример_2.mp3]]

雨ですが**外出しました**。

Хотя дождь, всё же вышел.

### Пример 3

![[Произношение/Глаголы/外出する_пример_3.mp3]]

在宅勤務の日でも、会議のために一度**外出し**、近くのカフェで資料を読み、帰宅してからまたパソコンに向かいました。

В день удалёнки я один раз вышел на встречу, почитал материалы в кафе рядом и вернулся к компьютеру.

## Заметки



**Спряжение:** III группа（サ変）: 外出します・外出しない・外出して

**Переходность:** Непереходный（自動詞）.

**Частицы:** Означает выйти из дома／места пребывания по делам, формальнее 出かける. 午後に外出する — выйти во второй половине дня, время с に. 仕事で外出する — отлучиться по работе, причина с で. Не приписывать ему обязательное に для любого «выхода»: направление уточняется отдельно.

**Особенности:** Сам факт выхода из дома／офиса; 外出中 — в данный момент отсутствует, потому что вышел.

## Кандзи-разбор

外(がい) вне; 出(しゅつ) выход; する
