# 下書き

したがき

черновик; предварительный набросок

![[Произношение/Канцелярия/下書き_слово.mp3]]

![[Картинки/Канцелярия/下書き.png]]

## Примеры

### Пример 1

![[Произношение/Канцелярия/下書き_пример_1.mp3]]

文章を**下書き**から始めます。

Начинаю писать текст с черновика.

### Пример 2

![[Произношение/Канцелярия/下書き_пример_2.mp3]]

先生に**下書き**を見てもらいます。

Покажу черновик учителю.

### Пример 3

![[Произношение/Канцелярия/下書き_пример_3.mp3]]

レポートの**下書き**を書き終えたあと、何度も直して、提出の前日にやっと清書しました。

После того как дописал черновик отчёта, несколько раз исправил и только накануне сдачи переписал чистовик.

## Заметки

名詞; сочетание 下 — нижний, 書き — писать; используется для обозначения предварительного текста

## Кандзи-разбор

下(した)=нижний, предварительный; 書(がき)=письмо, запись
