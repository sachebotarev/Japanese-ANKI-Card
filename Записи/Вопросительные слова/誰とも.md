# 誰とも

だれとも

ни с кем (с отрицанием)

![[Произношение/Вопросительные слова/誰とも_слово.mp3]]

![[Картинки/Вопросительные слова/誰とも.png]]

## Примеры

### Пример 1

![[Произношение/Вопросительные слова/誰とも_пример_1.mp3]]

**誰とも**話しません。

Ни с кем не разговариваю.

### Пример 2

![[Произношение/Вопросительные слова/誰とも_пример_2.mp3]]

今日は**誰とも**会いません。

Сегодня ни с кем не встречаюсь.

### Пример 3

![[Произношение/Вопросительные слова/誰とも_пример_3.mp3]]

新しいクラスで最初は**誰とも**話せなかったが、今は友だちができました。

В новом классе сначала ни с кем не мог говорить, но теперь завёл друзей.

## Заметки

疑問詞+とも; требует отрицания.
