# 島国

しまぐに

островное государство

![[Произношение/География/島国_слово.mp3]]

![[Картинки/География/島国.png]]

## Примеры

### Пример 1

![[Произношение/География/島国_пример_1.mp3]]

日本は**島国**です。

Япония — островное государство.

### Пример 2

![[Произношение/География/島国_пример_2.mp3]]

この**島国**には大きな港があります。

У этого островного государства есть большой порт.

### Пример 3

![[Произношение/География/島国_пример_3.mp3]]

**島国**では船が大切なので、港の歴史について調べました。

Поскольку для островного государства важны корабли, я изучил историю его порта.
