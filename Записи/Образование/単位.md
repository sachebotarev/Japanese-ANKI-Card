# 単位

たんい

зачётная единица (кредит в вузе)

![[Произношение/Образование/単位_слово.mp3]]

![[Картинки/Образование/単位.png]]

## Примеры

### Пример 1

![[Произношение/Образование/単位_пример_1.mp3]]

**単位**が足りません。

Кредитов не хватает.

### Пример 2

![[Произношение/Образование/単位_пример_2.mp3]]

この授業で**単位**がもらえます。

За этот курс можно получить кредит.

### Пример 3

![[Произношение/Образование/単位_пример_3.mp3]]

卒業に必要な**単位**を取るために、来学期も厳しいクラスを履修します。

Чтобы набрать нужные для выпуска кредиты, в следующем семестре возьму сложный курс.

## Заметки

名詞; 単位を取る/もらう.
