# 健康的

けんこうてき

здоровый; полезный для здоровья; оздоровительный

![[Картинки/Прилагательные_な/健康的.png]]

## Примеры

### Пример 1

![[Произношение/Прилагательные_な/健康的_пример_1.mp3]]

**健康的**な生活が大切です。

Здоровый образ жизни важен.

### Пример 2

![[Произношение/Прилагательные_な/健康的_пример_2.mp3]]

毎朝歩くのは**健康的**です。

Ходить пешком каждое утро полезно для здоровья.

### Пример 3

![[Произношение/Прилагательные_な/健康的_пример_3.mp3]]

忙しくても、**健康的**な食事を続けるようにしています。

Даже когда занят, я стараюсь продолжать здоровое питание.

## Заметки

ナ形容詞。`健康` — здоровье, `健康的` — имеющий здоровый характер.

## Кандзи-разбор

健(けん)=здоровый + 康(こう)=спокойное благополучие + 的(てき)=характер, свойство.
