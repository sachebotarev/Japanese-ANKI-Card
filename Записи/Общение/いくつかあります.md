# いくつかあります

いくつかあります

есть несколько; имеется некоторое количество

## Примеры

### Пример 1

![[Произношение/Общение/いくつかあります_пример_1.mp3]]

質問が**いくつかあります**。

Есть несколько вопросов.

### Пример 2

![[Произношение/Общение/いくつかあります_пример_2.mp3]]

この町には公園が**いくつかあります**。

В этом городе есть несколько парков.

### Пример 3

![[Произношение/Общение/いくつかあります_пример_3.mp3]]

観光案内所で聞くと、近くに見られる場所が**いくつかあります**と言われました。

Когда я спросил в туристическом информационном центре, мне сказали, что рядом есть несколько мест, которые можно посмотреть.

## Заметки

表現。`いくつか` значит «несколько»; используется с существительными и глаголом наличия.

## Кандзи-разбор

Кандзи нет: обычно пишется хираганой.
