# ちなみに

ちなみに

кстати; между прочим

![[Произношение/Общение/ちなみに_слово.mp3]]

![[Картинки/Общение/ちなみに.png]]

## Примеры

### Пример 1

![[Произношение/Общение/ちなみに_пример_1.mp3]]

**ちなみに**、明日は休みです。

Кстати, завтра выходной.

### Пример 2

![[Произношение/Общение/ちなみに_пример_2.mp3]]

**ちなみに**、この店は駅から近いです。

Кстати, этот магазин близко к станции.

### Пример 3

![[Произношение/Общение/ちなみに_пример_3.mp3]]

この町は古い建物で有名です。**ちなみに**、駅の近くに安いホテルもあります。

Этот город известен старыми зданиями. Кстати, рядом со станцией есть и недорогой отель.

## Заметки

副詞・接続表現。Используется для добавления связанной, но побочной информации.

## Кандзи-разбор

Кандзи нет: слово пишется хираганой.
