# 飲むためのもの

のむためのもの

вещь для питья; то, из чего или с помощью чего пьют

![[Произношение/Общение/飲むためのもの_слово.mp3]]

![[Картинки/Общение/飲むためのもの.png]]

## Примеры

### Пример 1

![[Произношение/Общение/飲むためのもの_пример_1.mp3]]

これは**飲むためのもの**です。

Это предмет для питья.

### Пример 2

![[Произношение/Общение/飲むためのもの_пример_2.mp3]]

コップは水を**飲むためのもの**です。

Стакан — это предмет для питья воды.

### Пример 3

![[Произношение/Общение/飲むためのもの_пример_3.mp3]]

小さい子どもが使いやすいように、軽くて割れにくい**飲むためのもの**を選びました。

Чтобы маленькому ребёнку было удобно пользоваться, я выбрал лёгкую и небьющуюся вещь для питья.

## Заметки

表現。`〜ためのもの` значит «вещь для того, чтобы...».

## Кандзи-разбор

飲(の)=пить; 物(もの) обычно пишется кандзи, но в этой фразе часто пишут хираганой.
