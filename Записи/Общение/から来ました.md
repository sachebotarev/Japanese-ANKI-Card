# から来ました

〜からきました

«Я приехал/пришла из …», «Я из …»

![[Произношение/Общение/から来ました_слово.mp3]]

![[Картинки/Общение/から来ました.png]]

## Примеры

### Пример 1

![[Произношение/Общение/から来ました_пример_1.mp3]]

私はロシア**から来ました**。

Я приехал из России.

### Пример 2

![[Произношение/Общение/から来ました_пример_2.mp3]]

彼はアメリカ**から来ました**。

Он приехал из Америки.

### Пример 3

![[Произношение/Общение/から来ました_пример_3.mp3]]

故郷は韓国で、三年前に日本**から来ました**。

Родина у меня Корея, а в Японию я приехал три года назад.

## Заметки

〜から — «из (какого-то места)»
来ました — «пришёл, приехал, прибыл» (прошедшая форма глагола 来る «приходить/прибывать»)

## Кандзи-разбор

来(き) = 

приходить, прибывать
