# 体にいい

## Примеры

### Пример 1

![[Произношение/Медицина/体にいい_пример_1.mp3]]

野菜は**体にいい**です。

Овощи полезны для здоровья.

### Пример 2

![[Произношение/Медицина/体にいい_пример_2.mp3]]

毎日歩くのは**体にいい**です。

Ежедневная ходьба полезна для тела.

### Пример 3

![[Произношение/Медицина/体にいい_пример_3.mp3]]

甘い物を減らしてよく寝るようにしたら、**体にいい**生活になったと感じます。

Уменьшив сладкое и лучше высыпаясь, чувствую, что образ жизни стал полезнее.

表現; 体にいい/悪い.
