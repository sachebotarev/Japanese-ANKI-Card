# 並木

なみき

аллея деревьев

![[Произношение/Природа/並木_слово.mp3]]

![[Картинки/Природа/並木.png]]

## Примеры

### Пример 1

![[Произношение/Природа/並木_пример_1.mp3]]

**並木**があります。

Там есть аллея деревьев.

### Пример 2

![[Произношение/Природа/並木_пример_2.mp3]]

駅の前に**並木**があります。

Перед станцией есть аллея деревьев.

### Пример 3

![[Произношение/Природа/並木_пример_3.mp3]]

春になると、駅前の**並木**に花が咲くので、毎年写真を撮ります。

Весной деревья в аллее перед станцией цветут, поэтому я фотографирую их каждый год.

## Заметки

Слово из словарных заметок Basic Kanji Books, тома 1–2.

## Кандзи-разбор

並 — ряд; 木 — дерево
