# 線路

せんろ

железнодорожный путь; рельсовый путь

![[Произношение/Транспорт/線路_слово.mp3]]

![[Картинки/Транспорт/線路.png]]

## Примеры

### Пример 1

![[Произношение/Транспорт/線路_пример_1.mp3]]

電車は**線路**を走ります。

Поезд едет по железнодорожному пути.

### Пример 2

![[Произношение/Транспорт/線路_пример_2.mp3]]

駅の近くで新しい**線路**を作っています。

Рядом со станцией строят новый железнодорожный путь.

### Пример 3

![[Произношение/Транспорт/線路_пример_3.mp3]]

工事が始まったので、作業員は道具を運んでから**線路**を直しました。

Поскольку начались работы, рабочие перенесли инструменты, а потом отремонтировали железнодорожный путь.

## Заметки

線路 обозначает путь, по которому ходят поезда и электрички. Для движения по нему часто используется конструкция 線路を走る.

## Кандзи-разбор

線 — линия; 路 — дорога, маршрут
