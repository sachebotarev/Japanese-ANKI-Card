# 道を渡るため

みちをわたるため

чтобы перейти дорогу; для перехода через дорогу

![[Произношение/Транспорт/道を渡るため_слово.mp3]]

![[Картинки/Транспорт/道を渡るため.png]]

## Примеры

### Пример 1

![[Произношение/Транспорт/道を渡るため_пример_1.mp3]]

**道を渡るため**、止まります。

Чтобы перейти дорогу, останавливаюсь.

### Пример 2

![[Произношение/Транспорт/道を渡るため_пример_2.mp3]]

**道を渡るために**、信号を待ちます。

Чтобы перейти дорогу, жду светофор.

### Пример 3

![[Произношение/Транспорт/道を渡るため_пример_3.mp3]]

**道を渡るために**横断歩道まで歩いて、信号が青になるまで待ちました。

Чтобы перейти дорогу, я дошёл до пешеходного перехода и ждал, пока загорится зелёный.

## Заметки

表現。`ために` показывает цель: «для того чтобы...». В `道を渡る` частица `を` отмечает путь, который пересекают.

## Кандзи-разбор

道(みち)=дорога + 渡(わた)=пересекать, переходить.
