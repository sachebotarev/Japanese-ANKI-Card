# 横断歩道

おうだんほどう

пешеходный переход; переход через дорогу

## Примеры

### Пример 1

![[Произношение/Транспорт/横断歩道_пример_1.mp3]]

**横断歩道**を渡ります。

Перехожу по пешеходному переходу.

### Пример 2

![[Произношение/Транспорт/横断歩道_пример_2.mp3]]

信号のある**横断歩道**を使ってください。

Пожалуйста, пользуйтесь пешеходным переходом со светофором.

### Пример 3

![[Произношение/Транспорт/横断歩道_пример_3.mp3]]

車が多かったので、少し遠くても**横断歩道**まで歩いてから道を渡りました。

Так как машин было много, я дошёл до пешеходного перехода, пусть он и был немного далеко, и только потом перешёл дорогу.

## Заметки

名詞。Буквально «дорога для поперечного перехода»; пользовательская подсказка: переход через дорогу.

## Кандзи-разбор

横(おう)=поперёк + 断(だん)=пересекать + 歩(ほ)=идти пешком + 道(どう)=дорога.
