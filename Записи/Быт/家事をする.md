# 家事をする

かじをする

заниматься домашними делами; делать работу по дому

![[Произношение/Быт/家事をする_слово.mp3]]

![[Картинки/Быт/家事をする.png]]

## Примеры

### Пример 1

![[Произношение/Быт/家事をする_пример_1.mp3]]

週末に**家事をします**。

На выходных занимаюсь домашними делами.

### Пример 2

![[Произношение/Быт/家事をする_пример_2.mp3]]

毎日少しずつ**家事をします**。

Каждый день делаю немного работы по дому.

### Пример 3

![[Произношение/Быт/家事をする_пример_3.mp3]]

共働きなので夫婦で**家事をして**、夜はいっしょに片づけるようにしています。

Оба работаем, поэтому делаем работу по дому и вечером вместе прибираемся.

## Заметки

する表現; 家事をする.

## Кандзи-разбор

家事(かじ)+する
