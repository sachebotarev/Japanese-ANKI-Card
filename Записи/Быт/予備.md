# 予備

よび

запас; резерв; запасной

![[Произношение/Быт/予備_слово.mp3]]

![[Картинки/Быт/予備.png]]

## Примеры

### Пример 1

![[Произношение/Быт/予備_пример_1.mp3]]

**予備**があります。

Есть запасной вариант.

### Пример 2

![[Произношение/Быт/予備_пример_2.mp3]]

かばんに**予備**のペンを入れました。

Я положил в сумку запасную ручку.

### Пример 3

![[Произношение/Быт/予備_пример_3.mp3]]

ペンが壊れるかもしれないので、家を出る前に**予備**を一つ持って行きました。

Поскольку ручка могла сломаться, перед выходом из дома я взял с собой одну запасную.

## Заметки

Может быть существительным или определением перед другим существительным через «の». Часто используется для вещей, которые держат на случай проблемы.

## Кандзи-разбор

予 — предыдущий, подготовительный; 備 — обеспечить
