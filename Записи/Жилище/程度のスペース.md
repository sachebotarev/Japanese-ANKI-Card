# 程度のスペース

ていどのスペース

пространство примерно такого размера; место, достаточное для чего-либо

![[Произношение/Жилище/程度のスペース_слово.mp3]]

![[Картинки/Жилище/程度のスペース.png]]

## Примеры

### Пример 1

![[Произношение/Жилище/程度のスペース_пример_1.mp3]]

一人分**程度のスペース**です。

Это пространство примерно на одного человека.

### Пример 2

![[Произношение/Жилище/程度のスペース_пример_2.mp3]]

机を置ける**程度のスペース**があります。

Есть место, достаточное для стола.

### Пример 3

![[Произношение/Жилище/程度のスペース_пример_3.mp3]]

小さなテントを二つ並べられる**程度のスペース**を確保してください。

Обеспечьте пространство, достаточное, чтобы поставить рядом две небольшие палатки.

## Заметки

Это модель, а не самостоятельное словарное существительное: количество или придаточное определение + 程度のスペース. 程度 задаёт приблизительную меру либо достаточный объём; スペース — физическое свободное место.

## Кандзи-разбор

程 — мера, степень; 度 — степень, мера
