# おかず

おかず

гарнир; блюдо, которое подают вместе с рисом

## Примеры

### Пример 1

![[Произношение/Еда/おかず_пример_1.mp3]]

今日の**おかず**は魚です。

Сегодня гарнир — рыба.

### Пример 2

![[Произношение/Еда/おかず_пример_2.mp3]]

### Пример 3

![[Произношение/Еда/おかず_пример_3.mp3]]

## Заметки

名詞; обычно в домашней кухне; подаётся вместе с рисом. Это общее разговорное слово для практически любого блюда, которое едят вместе с рисом
