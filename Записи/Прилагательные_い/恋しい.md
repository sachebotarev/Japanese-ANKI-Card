# 恋しい

こいしい

скучать (по кому-то); тосковать

![[Произношение/Прилагательные_い/恋しい_слово.mp3]]

![[Картинки/Прилагательные_い/恋しい.png]]

## Примеры

### Пример 1

![[Произношение/Прилагательные_い/恋しい_пример_1.mp3]]

家族が**恋しい**です。

Скучаю по семье.

### Пример 2

![[Произношение/Прилагательные_い/恋しい_пример_2.mp3]]

留学中、故郷の友だちが**恋しく**なりました。

Во время учёбы за границей заскучал по друзьям на родине.

### Пример 3

![[Произношение/Прилагательные_い/恋しい_пример_3.mp3]]

一人暮らしを始めて半年が過ぎたころ、実家の食べ物の匂いを思い出して、ふと両親のことが**恋しく**なり、電話をかけました。

Полгода жил один, вспомнил запах домашней еды, вдруг сильно заскучал по родителям и позвонил им.

## Заметки

い-прилагательное; 人が恋しい — скучать по человеку; 故郷が恋しい — тосковать по родине.

## Кандзи-разбор

恋(こい)しい=тосковать, скучать → 恋しい=скучный, тоскующий
